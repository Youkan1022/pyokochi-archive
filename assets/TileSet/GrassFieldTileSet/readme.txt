PASTEL 16PX PLATFORMER – GRASS FIELD TILESET
--------------------------------------------

STYLE
This tileset is designed in a soft pastel 16px pixel art style.
It is intended for platformer games but can also be used in RPGs or other 2D projects.

TILE SIZE
All tiles are designed for a 16x16 pixel grid.

CONTENTS
This tileset includes:

• 47-tile autotile compatible ground tiles(with reference file)
• Grass and soil terrain tiles
• Environment props (trees, plants, decorations)
• Background elements (sky, clouds, mountains)
• Additional: animated campfire sprite

AUTOTILE SUPPORT
The ground tiles follow the common 47-tile autotile layout used in many engines.

This makes them easy to use with:
- Godot Terrain Sets
- Unity Rule Tiles
- RPG Maker autotiles
- Other tile-based editors

FILE FORMAT
PNG (transparent background)

ENGINE COMPATIBILITY
Compatible with most 2D engines including:
- Godot
- Unity
- GameMaker
- RPG Maker
- Any engine supporting tilemaps

NOTES
Tiles are aligned to a 16x16 grid.
No trimming has been applied to ensure easy grid-based placement.
